换成自己的结果

下载 本页输入 CSV，替换四列：sample_id、reference、baseline、candidate。一行对应同一个样例，输出为空时保留空单元格。保存为 UTF-8 CSV，在仓库中运行：

python scripts/compare.py --input your-pairs.csv --output exports/my-comparison

用浏览器打开输出目录的 index.html 即可筛选。计算在本地完成，无需上传数据或配置模型密钥。输出目录必须尚不存在。

计算范围

沿用 cer-v1 / cer-normalize-v1：NFKC、casefold，仅保留汉字、拉丁字母和十进制数字。这里只比较转写文本，不评估音频、语义、翻译、意图或动作，也不设置质量通过门槛。不支持该归一化范围之外的通用多语种评测。
